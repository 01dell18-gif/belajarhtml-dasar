# WebCraft: Media Belajar Web Desain & HTML Dasar Ramah Pemula 🚀

**WebCraft** adalah platform media pembelajaran web interaktif yang dirancang khusus untuk pemula yang ingin belajar membuat website dari nol tanpa pusing dengan istilah teknis rumit. Aplikasi ini berbentuk **Single File (`index.html`)** mandiri (*Zero-dependency*) yang dapat langsung dibuka cukup dengan **klik dua kali** di komputer atau diunggah ke GitHub Pages.

---

## 💡 Konsep Sederhana: 3 Pilar Website
Untuk mempermudah pemahaman, bayangkan membuat website seperti **Membangun Rumah**:
1. **🧱 HTML (Kerangka Rumah):** Menyusun dinding, pintu, dan jendela (menentukan ada teks judul, paragraf cerita, dan tombol).
2. **🎨 CSS (Cat & Dekorasi):** Memberi warna cat dinding, merapikan perabot, dan mempercantik sudut kartu agar sedap dipandang.
3. **⚡ JavaScript (Saklar Listrik & Bel):** Membuat bel berbunyi dan lampu menyala saat ditekan (membuat tombol bisa diklik dan bereaksi memberi sapaan).

---

## ✨ Fitur-Fitur Utama WebCraft

### 1. 🚀 Panduan Interaktif "Langkah Demi Langkah" (Step-by-Step)
Fitur unggulan di mana pemula bisa melihat langsung evolusi proyek web secara bertahap:
- **Langkah 1: HTML Saja** $\rightarrow$ Tampilan kerangka polos hitam-putih standar browser.
- **Langkah 2: Tambah CSS** $\rightarrow$ Tampilan seketika berubah cantik, rapi di tengah, dan berwarna ungu modern.
- **Langkah 3: Tambah JavaScript** $\rightarrow$ Tombol menjadi interaktif, bisa diklik, memunculkan sapaan, dan berubah warna hijau.
- **Langkah 4: Hasil Jadi 1 File Lengkap** $\rightarrow$ Penyatuan utuh HTML, CSS, dan JS dalam 1 file yang siap diunduh (*1-click download*).

### 2. 📚 5 Modul Pembelajaran dengan Bahasa Santai
- **Modul 1 (HTML5 Dasar):** Belajar tag judul (`<h1>`), paragraf (`<p>`), dan formulir isian (`<form>`).
- **Modul 2 (CSS3 Dasar):** Mengatur warna (`background-color`), jarak (`padding`/`margin`), sudut membulat (`border-radius`), dan Flexbox.
- **Modul 3 (JavaScript Dasar):** Menangkap klik pengunjung (`addEventListener`) dan mengubah tulisan secara langsung tanpa refresh.
- **Modul 4 (Database Google Sheets):** Menyimpan nama dan pesan pengunjung langsung ke tabel Google Spreadsheet gratis tanpa sewa server backend.
- **Modul 5 (Publikasi GitHub Pages):** 4 langkah mudah meng-online-kan website ke seluruh dunia secara gratis.

### 3. 🎨 6 Visualizer Studio Interaktif
- **Box Model Lab:** Geser slider untuk melihat batas Margin, Border, dan Padding secara visual.
- **Flexbox Lab:** Atur barisan kotak ke samping atau ke bawah dengan rak fleksibel otomatis.
- **CSS Grid Builder:** Tata letak 2-dimensi untuk struktur halaman lengkap dan galeri kartu.
- **Keyframe & Animasi:** Uji coba efek gerak *Pulse*, *Bounce*, *Spin*, *Shake*, dan *Float*.
- **Hover Micro-Interactions:** Efek kartu terangkat saat disentuh kursor kursor mouse.
- **Semantic Inspector:** Membandingkan kerapian tag semantik vs div polos.

### 4. 💻 Live Code Sandbox
Editor mini HTML, CSS, dan JavaScript bawaan di browser dengan pratinjau langsung dan tombol **Unduh File .html**.

### 5. 📡 Form & Google Sheets Tester
Simulator form pengiriman data langsung ke tabel spreadsheet dengan mode pengujian cepat.

### 6. 🏆 Kuis Santai & Sertifikat Digital
10 pertanyaan interaktif pilihan ganda dengan penjelasan ramah dan generator **Sertifikat Kelulusan** yang bisa dicetak/disimpan ke PDF.

## 🚀 Cara Menjalankan Secara Lokal

1. Buka folder proyek ini di komputer Anda: `d:\Coba\App Belajar HTML\`.
2. Klik dua kali (double-click) file `index.html`.
3. Aplikasi akan langsung terbuka di Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari tanpa perlu koneksi internet ataupun instalasi aplikasi tambahan!

---

## 🌐 Cara Publikasi Gratis ke GitHub Pages

1. Buka [github.com](https://github.com) dan buat repositori baru (misal: `website-pertama-saya`).
2. Unggah file `index.html` langsung di **root folder** repositori Anda.
3. Masuk ke tab **Settings** repositori $\rightarrow$ klik menu **Pages** di sebelah kiri.
4. Pada bagian **Build and deployment**, pilih Source: `Deploy from a branch` $\rightarrow$ Branch: `main` / `root` $\rightarrow$ klik **Save**.
5. Dalam 30-60 detik, website Anda sudah aktif secara global di alamat:
   ```
   https://<username-anda>.github.io/website-pertama-saya/
   ```
